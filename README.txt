METER PAMS — HTML TAHAP AWAL

Buka index.html di browser atau unggah ke GitHub Pages.

Ini adalah prototipe tampilan responsif. Belum terhubung ke Neon dan formulir sengaja tidak menyimpan data.
Sebelum digunakan produksi:
1. Buat backend/API (misalnya Cloudflare Workers) untuk mengakses Neon.
2. Simpan connection string Neon sebagai secret backend, jangan di HTML/GitHub.
3. Tambahkan login, autentikasi, otorisasi per peran, validasi server-side, dan audit log.
4. Implementasikan perhitungan tarif bertingkat, denda bulanan, pembayaran, dan backup terjadwal.
5. Uji semua alur sebelum memasukkan data pelanggan nyata.
